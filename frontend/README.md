# frontend

前端代码目录。

## 用途
放 Vue 3 网页项目的全部代码，也就是用户浏览器里看到的界面。

## 后续会有的内容
- `src/` — Vue 组件和页面
- `package.json` — 前端依赖配置
- `vite.config.js` — 构建工具配置

## 本地启动与接口地址

- 执行 `npm run dev -- --host 127.0.0.1` 后，网页默认使用 `http://127.0.0.1:5173`。
- 开发时，Vite 会把 `/api` 与 `/ws` 请求转发到本机后端 `8080` 端口，因此页面代码不再写死后端地址。
- 部署时，前后端放在同一网站域名下即可；只有必须分开部署时，才复制 `.env.example` 为 `.env.local` 并填写完整的 API 与 WebSocket 地址。
