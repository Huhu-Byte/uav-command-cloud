# 数据库部署说明

## 一、本机开发

后端默认使用 H2 文件数据库，文件保存在 `C:\Users\x\.uav-command`。第一次启动会自动创建返航操作记录表和告警确认记录表，不需要安装或配置数据库软件。

## 二、共享 MySQL 部署

推荐将后端部署在阿里云 ECS，再将 MySQL 放在同地域、同私有网络的 RDS 中。这样同事只访问网页，数据库不需要暴露到公网。

后端使用 MySQL 时需要设置以下环境变量：

```powershell
$env:SPRING_PROFILES_ACTIVE = 'mysql'
$env:UAV_DB_URL = 'jdbc:mysql://数据库地址:3306/uav_command?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai'
$env:UAV_DB_USERNAME = '数据库账号'
$env:UAV_DB_PASSWORD = '数据库密码'
```

变量设置后再启动后端。数据库保持为空即可；Flyway 会自动创建所需表并记录脚本执行历史。

## 三、安全规则

- 不把数据库密码写进 `application.yml`、前端代码或 Git。
- RDS 只允许 ECS 内网访问；临时本机联调需要开放时，只把同事的固定公网 IP 加入白名单。
- 正式部署使用专门的数据库账号，不使用管理员账号。
